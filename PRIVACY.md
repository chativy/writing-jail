# Privacy Policy

**Effective date:** November 1, 2026

Writing Jail is a local macOS text editor. It does not collect, transmit, sell,
or share personal information.

## Data Collection

Writing Jail does not require an account and contains no analytics, telemetry,
advertising, tracking, or cloud synchronization. We do not receive information
about your documents, activity, device, or usage.

## Local Files and Storage

Writing Jail accesses only files and folders that you explicitly select. The
contents of the selected Markdown file are read and written locally to provide
editing and auto-save functionality.

The app also stores a local recovery draft at:

`~/Library/Application Support/WritingJail/draft.txt`

App preferences, such as theme and display settings, are stored locally by
macOS. This local data is not transmitted to the developer or any third party.
You can delete the recovery draft and app preferences at any time.

## Accessibility and Keyboard Events

If you enable Input Blocking, macOS may request Accessibility permission.
Writing Jail uses that permission only to block shortcuts that would leave the
active focus session, such as Cmd-Tab and Mission Control.

Writing Jail does not record, log, store, or transmit the keys you type.
Accessibility permission is optional; without it, the app runs in Limited Mode.

## Data Sharing

Writing Jail does not sell, rent, disclose, or provide personal data to third
parties. No document content or usage data is sent to a server operated by the
developer.

## Changes to This Policy

This policy may be updated if Writing Jail's data practices change. The current
version will always be published in this repository.

## Contact

Privacy questions can be submitted through the repository's GitHub Issues page.
