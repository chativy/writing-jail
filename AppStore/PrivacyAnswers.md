# App Privacy Answers

Use these answers in App Store Connect's App Privacy questionnaire.

## Data Collection

- Does the app collect data? **No**
- Is data linked to the user? **Not applicable**
- Is data used for tracking? **No**

Writing Jail has no account system, analytics, telemetry, advertising, or
cloud synchronization. Documents, recovery drafts, preferences, and custom
image paths remain on the user's Mac.

## Permission Disclosure

Accessibility permission is optional and used only to block shortcuts during
an active focus session. Keyboard input is intercepted in memory and is not
recorded, persisted, or transmitted. This behavior is disclosed in
`PRIVACY.md` and in the App Review notes.
