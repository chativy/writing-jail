Writing Jail is a local Markdown editor with an optional focus-lock feature.

The app does not require an account and includes no analytics, telemetry, advertising, cloud synchronization, or network-based data collection.

When the user chooses Configure Input Blocking, the app may request macOS Accessibility permission. Accessibility is used only to intercept shortcuts that would leave an active focus session, such as Cmd-Tab and Mission Control. Writing Jail does not record, log, store, or transmit keyboard input.

On macOS 27 and later, the system does not allow the app to register itself for Accessibility access. The app copies its bundle path and directs the user to add WritingJail.app manually with the + button in Device Control and Data Access.

If Accessibility permission is not granted, the app continues to work in Limited Mode using an in-app full-screen kiosk presentation.

Hold Control-Option-Escape for five seconds to end a focus session early. The focus lock cannot prevent forced restart or physical power changes.
